## 5. Motion (motion.dev)
**URL:** https://motion.dev/  
**Type:** Animation Library  
**Previously:** Framer Motion

JavaScript & React animation library — free, MIT licensed, production-ready.

### Key Features
1. **Independent transforms** — Animate `x`, `y`, `rotate`, `scale` without wrappers
2. **Scroll animation** — Hardware-accelerated via `ScrollTimeline`
3. **Native gestures** — `hover`, `press`, `drag`
4. **Layout animation** — Animate between layouts with `layout` prop
5. **Spring physics** — Real spring math for natural reactions
6. **Exit animation** — `AnimatePresence` keeps elements alive during exit
7. **Timeline sequences** — `variants`, `stagger` for complex motion
8. **Motion values** — `useMotionValue` drives real-time animations

### Advantages
- **Tiny footprint** — APIs up to 90% smaller than GSAP
- **Hybrid engine** — JavaScript + hardware-accelerated browser APIs
- **Built for AI** — Agent-compatible documentation, skills, and API

### Platforms
- React
- JavaScript (Vanilla)
- Vue

### Latest Releases
- v13.4.0 (Sep 13, 2026) — Added `AnimateView` for React 19.3
- v13.3.0 (Sep 13, 2026) — 80% faster spring retargeting, 10% smaller `animate`, 20% faster startup

### Ecosystem
- **Motion UI** — Production-ready animated sections (launched July 22, 2026)
- **AI Kit** — 450+ example sources, performance audits, CSS springs for agents
- **MotionScore** — Animation performance issue detection

### Partners
- Framer — Powers animations across hundreds of thousands of sites
- Cursor — One-click open-in-AI examples
- Sponsors: Linear, Figma, Sanity, Clerk
